# Deep Research Skill

OpenClaw skill for running Gemini Deep Research and returning a cited markdown report.

## Included

- `deep-research/SKILL.md`
- `deep-research/deep-research.mjs`
- `deep-research.skill` (packaged artifact)

## Security

This repository does **not** include any real API keys.
The script reads `GEMINI_API_KEY` from the environment at runtime.

## Publish target

- GitHub source repo
- ClawHub skill publish from `deep-research/`
